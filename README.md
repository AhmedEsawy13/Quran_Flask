# Quran_Flask

Quran_Flask is a web application that provides access to the Holy Quran. It is built using Flask and deployed on Vercel.

## Features

- Access to the Quran with translations.
- User-friendly interface with a clean design.
- Word-by-word highlighting.
- Support for different fonts.
- Multiple reciters available.
- Supports multiple languages for translation.
- Responsive design for mobile and desktop users.

## Language Composition

- **JavaScript**: 52.7%
- **Python**: 20.9%
- **CSS**: 17.1%
- **HTML**: 9.3%

## Installation

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/AhmedEsawy13/Quran_Flask.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Quran_Flask
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the Flask application:
   ```bash
   flask run
   ```

## Deployment

This project is deployed on Vercel. You can access it [here](https://quran-flask-vercel.vercel.app).
